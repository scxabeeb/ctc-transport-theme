# Capital Transportation Company (CTC) WordPress Theme

Modern, responsive WordPress theme for Capital Transportation Company (CTC) Somalia.

## Features
- Complete single-page layout matching the CTC development & content brief
- Integrated official CTC main logo and client logos (CARE, World Vision, Adam Smith, SIDRA, INSO, PSI, NIS, MOH PL, MOPEDIC, MOJ)
- Dynamic vehicle selection linked directly to the booking form
- Schema.org JSON-LD Structured Data for Organization and Vehicle Rental Service
- Responsive Tailwind design with FontAwesome icons

## Installation
1. Download this repository as a ZIP archive (`Code` -> `Download ZIP`).
2. In WordPress Admin, navigate to **Appearance > Themes > Add New > Upload Theme**.
3. Choose the ZIP file and click **Install Now**, then **Activate**.
4. Set a static front page under **Settings > Reading** (select front-page template or home).
